feat(config)!: drop the mockserver.workers alias

The old property name was read after MOCK_SERVER_WORKERS and WORKERS;
one name too many for one setting.

```release-note
`mockserver.workers` is no longer read. A deployment that sets it
sets `MOCK_SERVER_WORKERS` (or `WORKERS`) to the same value instead.
```
