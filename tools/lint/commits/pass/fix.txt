fix(forward): retry a request whose connection was reset

A reset connection failed the forwarded request at once, so a client
saw a 502 for a transient fault. It is now retried like a refused
connection, a bounded number of times.

```release-note
A forwarded request whose connection is reset is retried, so a client
no longer sees a 502 for a transient fault.
```
