## [9.2.0] - YYYY-MM-DD

### Action required

- `mockserver.workers` is no longer read. A deployment that sets it sets `MOCK_SERVER_WORKERS` (or `WORKERS`) to the same value instead. (config, ee71a89)

### Features

- An expectation initialisation file may be YAML as well as JSON. (control, 6d17d77)
- The webhook's chart takes `priorityClassName` for its pods. (k8s-webhook, 3ddd61f)

### Bug fixes

- A forwarded request whose connection is reset is retried, so a client no longer sees a 502 for a transient fault. (forward, b0d13d6)
- A request body over the size limit is answered 413 instead of 400. (cf0abe1)
- An error answer names the request's trace_id, as its log line does. (control, 32472a1)

### Performance

- An expectation with a Velocity template answers faster and in less memory. (templates, 30c919b)

### Other changes

- The guide says how to load expectations without rebuilding the image. (e069484)
